About

I'm Clément, a developer and a gamer at heart. I make mobile games that are ridiculously simple to start and impossible to put down.

It started solo with Flappy Vertical. Block Drift followed, with more than 2,000 levels built end to end, from the code to the last pixel.

Today some projects are still solo adventures and others are built together. Robot Defense, built in Unity, is co-developed with a friend. And I'm nowhere near done.
